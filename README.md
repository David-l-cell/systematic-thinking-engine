# Systematic Thinking Engine v2.3

> A cross-platform, hot-pluggable systematic thinking engine for AI Agents (Qclaw / OpenClaw / Hermes).
> Drives deep learning via 10 scenario-anchored questions, cross-domain integration, rigor assurance, and a closed-loop experience learning cycle.

## Features

- M1: Scenario-Anchored Deep Learning (10 questions across ≥3 domains, Quality Gate)
- M2: Closed-Loop Experience Learning (Auto-failure-recovery, experience repository persistence)
- M3: Cross-Domain Knowledge Integration (4-axis scoring, universal principle extraction)
- M4: Rigor & Truthfulness Assurance (claim verification, fabrication prevention audit)
- Bootstrap layer with content-type templates and auto-trigger
- Token budget control (MAX 2000 chars output)

## Quick Start

1. Copy this folder to your Agent skills directory
2. Trigger via: ` /think deep [content] ` or auto-trigger on context ≥ 500 chars
3. See SKILL.md for full command reference
